# CSV Data Summarizer - Example Prompts & Patterns

## Example Prompts

> "Here's sales_data.csv. Can you summarize this file?"

> "Analyze this customer data CSV and show me trends."

> "What insights can you find in orders.csv?"

## Expected Output Pattern

The skill must produce a response structured as follows:

1.  **Dataset Overview**: Rows, columns, types.
2.  **Summary Statistics**: Relevant metrics for the data type.
3.  **Missing Data Analysis**: Quality check results.
4.  **Visualizations**: List of created plots (e.g., `time_series_analysis.png`).
5.  **Actionable Insights**: Concise bullets based on the data.
